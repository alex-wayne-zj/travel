# 仓库内容与隐私边界

公开源码仅包括应用实现、依赖锁、公共图标、通用部署模板、自动化测试与合成示例。`src/itinerary.json` 是虚拟旅行样例：公开地点的名称、位置及参考链接可用于演示，日期、票务与住宿安排不代表真实预订。

以下资料必须留在仓库之外：

- 账号密码、邀请码、会话、CSRF token、私钥及实际环境配置。
- SQLite 数据库及 WAL/SHM、数据库导出、备份和私人离线行程。
- 包含账号、真实路线、服务器身份或凭据位置的截图、日志、交接与部署报告。
- 实际域名、证书配置、生产路径等机器配置；使用 `deploy/*.example` 作为通用模板。

`.gitignore` 排除构建产物、临时验收资料、数据库、环境文件、缓存和本地运维文档；通用 `.env.example` 可以提交。忽略规则不会移除已经提交的文件，因此每次提交前仍须检查暂存内容，尤其是文档、测试夹具、默认地址与新加入的二进制文件。

自托管时复制部署模板，填写自己的 HTTPS 域名和证书，显式设置 `TRAVEL_ORIGIN`；密钥由服务器私有配置提供。测试只使用临时账号、合成邀请名和独立数据库，不读取生产凭据。演示数据与真实用户数据保持分离，不将生产数据库或地图验收导出放入仓库。
